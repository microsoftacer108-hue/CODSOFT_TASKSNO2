**Task 2: Student Grade Calculator**

As part of my **CodSoft** internship, I developed a Student Grade Calculator using Java. The program takes the number of subjects and marks obtained in each subject as input. It then calculates the total marks and average percentage and assigns a grade based on the student's performance. The program also validates the entered marks to ensure they are within the valid range of 0 to 100. This project provided practical experience with Java input handling, loops, calculations, conditional statements, validation, and grade-based decision making.
